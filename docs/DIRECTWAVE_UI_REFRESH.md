# StudioWave DirectWave UI refresh

Original mobile adaptation inspired by Ableton Live device conventions: graphite panels, teal rotary arcs, amber accents, compact parameter readouts, sample preview and device-chain tiles. The generic oscillator-test row is replaced with sample/filter/ADSR/tone/FX sections and touch-drag knobs. Mixer Volume/Pan are also intended to use the rotary-control component.

Filter/envelope and EQ Eight/Saturator/Reverb tiles are UI scaffolding until DSP is integrated. CI downloads six CC0 WAVs before building; actual sampler-voice playback is not yet implemented.
