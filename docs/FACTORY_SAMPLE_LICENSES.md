# StudioWave Factory Sample — DirectWave

- `one_shot.wav` is an original, procedurally generated StudioWave starter sound bundled for offline DirectWave use.
- Format: WAV / PCM signed 16-bit / mono / 22,050 Hz / 0.72 seconds.
- It is **not** represented as a downloaded third-party sample and is not the unverified exact file named “One Shoot.wav”.
- A possible source for replacing or supplementing it with third-party audio is [sound-cc0](https://github.com/code4fukui/sound-cc0), whose README dedicates its samples to CC0 1.0. The current bundled asset was generated for StudioWave rather than copied from that repository.

The sample is stored in `app/src/main/res/raw/one_shot.wav` and is available offline after installation.
